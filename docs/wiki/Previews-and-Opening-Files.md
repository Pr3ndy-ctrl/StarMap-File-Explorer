# Previews and opening files

Click a file's star to see its details in the right-hand panel.

## What can be shown

| Type | Shown as |
|---|---|
| Audio: MP3, WAV, M4A, AAC, OGG, Opus, FLAC, AIFF | A player |
| Video: MP4, M4V, MOV, WebM | A player |
| Images: PNG, JPEG, WebP, GIF, SVG, ICO, BMP | The picture |
| PDF | The browser's PDF viewer |
| Word documents (.docx) | The formatted text |
| Text and code: Markdown, text, JSON, CSV, YAML, HTML, CSS, JavaScript, Python and many more | The text, as plain text |

Whether a video or audio format plays depends on your browser. Safari plays HEVC (H.265) video; Chrome and Firefox may not.

**Larger view** widens the panel. **Open in a new tab** shows the file in its own browser tab.

## Buttons for every file

- **Copy full path** copies where the file is, ready to paste into Finder (Go, then Go to Folder), File Explorer's address bar or a terminal.
- **Open file** opens it in its usual app. For safety, StarMap refuses to open programs, scripts and installers, such as `.app`, `.exe`, `.bat`, `.sh`, `.command`, `.ps1`, `.py` and `.dmg`. Use **Show in Finder** for those.
- **Show in Finder** (macOS) or **Show in File Explorer** (Windows) opens the file's folder with the file selected. On Linux, it opens the folder in your file manager.

If a file has moved or been deleted since the last scan, StarMap says so; **Re-scan** updates the map.
